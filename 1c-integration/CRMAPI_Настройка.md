# Настройка HTTP сервиса в Конфигураторе 1С

## Шаг 1: Создать Общий модуль

Конфигурация → Общие → Общие модули → ПКМ → Добавить

- **Имя:** `CRMАПИСервер`
- **Синоним:** CRM API Сервер
- **Свойства:**
  - ✅ Сервер
  - ❌ Клиент (управляемое приложение)
  - ❌ Клиент (обычное приложение)
  - ❌ Внешнее соединение
  - ❌ Вызов сервера

Вставить код из `CRMАПИСервер.bsl`

---

## Шаг 2: Создать HTTP сервис

Конфигурация → Общие → HTTP-сервисы → ПКМ → Добавить

- **Имя:** `CRMAPI`
- **Синоним:** CRM API
- **Корневой URL:** `/crm`
- **Автоиспользование сеансов:** ❌ (не использовать)

---

## Шаг 3: Создать шаблоны URL

В дереве `CRMAPI` → ПКМ → Добавить шаблон URL

### Шаблон 1: Клиенты
- **Имя:** `Клиенты`
- **Шаблон URL:** `/v1/clients`
- Добавить метод: **GET** → Имя обработчика: `КлиентыПолучить`

### Шаблон 2: Договоры
- **Имя:** `Договоры`
- **Шаблон URL:** `/v1/contracts`
- Добавить метод: **GET** → `ДоговорыПолучить`

### Шаблон 3: Счета-фактуры
- **Имя:** `СчетаФактуры`
- **Шаблон URL:** `/v1/invoices`
- Добавить метод: **GET** → `СчетаФактурыПолучить`

### Шаблон 4: Платежи
- **Имя:** `Платежи`
- **Шаблон URL:** `/v1/payments`
- Добавить метод: **GET** → `ПлатежиПолучить`

### Шаблон 5: Долги
- **Имя:** `Долги`
- **Шаблон URL:** `/v1/debts`
- Добавить метод: **GET** → `ДолгиПолучить`

### Шаблон 6: Финансовое резюме клиента
- **Имя:** `ФинансовоеРезюме`
- **Шаблон URL:** `/v1/client-financial-summary/{client_id}`
- Добавить метод: **GET** → `ФинансовоеРезюмеПолучить`

---

## Шаг 4: Создать Константы

Конфигурация → Общие → Константы → ПКМ → Добавить (для каждой):

| Имя | Тип | Описание |
|-----|-----|---------|
| `CRMAPIЛогин` | Строка (50) | Логин для Basic Auth |
| `CRMAPIПароль` | Строка (100) | Пароль для Basic Auth |
| `CRMAPIТокен` | Строка (200) | Bearer токен (альтернатива) |

После создания: Предприятие → Заполнить значения констант:
- Логин: `crm_user`
- Пароль: `ВашНадёжныйПароль2026!`
- Токен: (сгенерировать длинную случайную строку, например UUID)

---

## Шаг 5: Сохранить и опубликовать

1. Конфигурация → Сохранить конфигурацию (Ctrl+S)
2. Конфигурация → Обновить конфигурацию базы данных (F7)
3. Администрирование → Публикация на веб-сервере...
   - Выбрать публикацию (или создать новую)
   - В разделе "HTTP-сервисы" отметить ✅ `CRMAPI`
   - Нажать "Опубликовать"

**Проверить:**
```
http://<сервер>/<публикация>/hs/crm/v1/clients
```

---

## Шаг 6: Проверить имена документов

В Конфигураторе убедиться в наличии:
- `Документ.СчетФактураВыданный` (или аналог — например `ОтгрузкаТоваровУслуг`)
- `Документ.ПоступлениеНаРасчетныйСчет`

Если имена отличаются — исправить в `CRMAPI_HTTPСервис.bsl`.

Поле "Дата оплаты" в счёт-фактуре может называться `СрокОплаты` или `ДатаОплаты` — проверить в Конфигураторе.
